# 🛍️ Customer Spending Prediction

## 📌 Project Overview

Customer Spending Prediction is a Machine Learning-based web application developed using **Python and Streamlit**. The application predicts the estimated spending amount of a customer based on various customer-related attributes.

The project aims to help businesses understand customer spending patterns and make better data-driven decisions.

## 🎯 Objectives

- Predict customer spending based on customer information.
- Understand the relationship between customer attributes and spending behaviour.
- Provide an interactive and user-friendly prediction interface.
- Demonstrate the practical application of Machine Learning in customer analytics.

## 🚀 Features

- Interactive web application built using Streamlit.
- User-friendly input fields for customer details.
- Customer spending prediction in Indian Rupees (₹).
- Multiple input options using number fields and dropdown menus.
- Real-time prediction through the Predict Spend button.
- Simple and clean dashboard interface.

## 📊 Input Features

The application uses the following customer attributes:

- Annual Income
- Membership Level
- Preferred Category
- Website Visits
- Previous Purchase
- City Tier
- Discount Used

## 🛠️ Technologies Used

- **Programming Language:** Python
- **Framework:** Streamlit
- **Machine Learning:** Predictive Model
- **Development Environment:** Visual Studio Code

## ⚙️ Installation and Setup

Follow these steps to run the project locally.

**1. Clone the repository**

```bash
git clone <your-repository-url>
```

**2. Navigate to the project directory**

```bash
cd Customer-Spending-Prediction
```

**3. Install the required dependencies**

```bash
pip install -r requirements.txt
```

**4. Run the Streamlit application**

```bash
streamlit run app.py
```

**5. Open the application**

The application will open in your browser, usually at:

```text
http://localhost:8501
```
